7. CONSUMING cortex_static.meta / .lgbm VS. cortex_static.onnx
============================================================

  cortex_static.meta is a Python PICKLE (models/static_lgbm.py:121-122
  writes it via pickle.dump(meta, fh, protocol=pickle.HIGHEST_PROTOCOL);
  :128-129 reads it via pickle.load(fh) -- confirmed by disassembling the
  actual deployed file with pickletools, and by loading it: its dict is
  {'calibrator': <models.static_lgbm.PlattCalibrator>, 'feature_count':
  2568, 'num_iterations': 3000, 'model_hash': 'acfa5a757aa13cd0'}).
  PlattCalibrator wraps sklearn.linear_model.LogisticRegression
  internally (models/static_lgbm.py:63-74) -- unpickling it needs BOTH
  the models.static_lgbm module (for the PlattCalibrator class) and a
  scikit-learn compatible with the pinned range in requirements.txt
  (scikit-learn>=1.4,<2.0). Evidence (pickletools.dis() on the actual
  deployed cortex_static.meta, GLOBAL/STACK_GLOBAL opcodes -- the two
  classes the pickle stream references by module+name, byte offsets
  shown):
    offset  66 STACK_GLOBAL  'models.static_lgbm' 'PlattCalibrator'
    offset 133 STACK_GLOBAL  'sklearn.linear_model._logistic' 'LogisticRegression'
  Loading a pickle executes arbitrary code by design -- do this ONLY for
  files produced by this repo's own training pipeline, never for an
  untrusted or externally-supplied .meta file.

  scikit-learn does not guarantee that a pickled estimator loads across
  versions; these artifacts were built with scikit-learn 1.7.2 (section
  0). Use the same version, or use the ONNX file, which has no such
  dependency. The repo's requirements.txt range (>=1.4,<2.0) is a
  supported-runtime range, not a pickle-compatibility guarantee.

  cortex_static.onnx already contains the Platt calibrator baked into the
  graph (section 3 above) -- a non-Python consumer, or any consumer that
  wants to avoid the pickle-loading requirement above, needs ONLY
  cortex_static.onnx plus the two full-precision thresholds in section 2.
  It does not need cortex_static.lgbm or cortex_static.meta at all.
